# NSH runtime logo

Source: https://nsh.dev/brand/nsh-logo-solid-black.svg (downloaded 2026-11-05).
Brand page: https://nsh.dev/brand

`NSHMark` reproduces the official SVG geometry in its original 128×128 viewBox,
with the existing runtime foreground tint in place of the SVG ink color.
The mark identifies NSH in the runtime badges of detected applications.

On 2026-11-05, Jason Lee replied to our request to use and distribute the
single-color logo in DuoUpdater, including theme-dependent coloring and sizing:

> 可以用与标识你的应用用 NSH 开发，这些 Logo 图案都是可以使用的。

The request explained that DuoUpdater identifies frameworks used by installed
applications and does not imply endorsement. No additional attribution or
color requirements were stated in the reply. This records the permission for
this use; it does not claim a general trademark license.
